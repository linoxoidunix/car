# 22. `crates/cra-server/assets/style.css` — оформление

**Размер:** 255 строк. **Задача:** оформить интерфейс, поддержать светлую и
тёмную темы, задать цветовое кодирование элементов схемы.

Логики здесь нет — только внешний вид. Но несколько решений стоит объяснить,
потому что от них зависит читаемость схемы.

## Цветовые переменные

```css
:root {
  color-scheme: light dark;
  --bg: #f3f4f6;        --panel: #ffffff;     --side: #f9fbff;   --hover: #eff1f4;
  --border: #e5e7eb;    --dot: #d1d5db;
  --text: #262626;      --muted: #71757e;
  --accent: #4d6bfe;    --accent-fg: #ffffff;
  --accent-soft: #dbeafe; --accent-ink: #3a54e0;
  --primary: #4d6bfe;   --primary-hover: #3d5af1; --primary-fg: #ffffff;
  --ok: #17803d;        --warn: #3a54e0;      --err: #dc2626;
  --event: #eff6ff;     --event-br: #8fb2fb;  /* события — голубые */
  --gate: #ebf7ef;      --gate-br: #6fb48a;   /* элементы — зелёные */
  --sel: #4d6bfe;                              /* выделение — синее */
  --edge: #a0a6b2;      --scroll: #d1d5db;
  --shadow: …;          --backdrop: rgba(20, 24, 40, .35);
  --radius: 10px;       --radius-lg: 16px;
  --font: Inter, "Segoe UI", system-ui, -apple-system, Roboto, "Noto Sans", sans-serif;
  --mono: ui-monospace, "Cascadia Code", "Consolas", monospace;
}
```

Все цвета собраны в одном месте как пользовательские свойства CSS. Дальше в
файле нет ни одного шестнадцатеричного кода — только `var(--…)`. Смена палитры
целиком — это правка одного блока.

## Тёмная тема

```css
@media (prefers-color-scheme: dark) {
  :root {
    --bg: #202124; --panel: #292a2d; --side: #212327; --hover: #35363b;
    --border: #3a3b40; --dot: #404248; --text: #f3f5fa; --muted: #a0a4ad;
    --accent: #6f9bff; --accent-fg: #0e1222; --accent-soft: #1f3460; --accent-ink: #a9c8ff;
    --primary: #4d6bfe; --primary-hover: #5f7bff;
    --ok: #4cc27a; --warn: #a9c8ff; --err: #f87171;
    --event: #1e2d4a; --event-br: #4f7fd9; --gate: #22352a; --gate-br: #5aa476;
    --sel: #6f9bff; --edge: #6b707a; --scroll: #4a4c52;
    --shadow: …; --backdrop: rgba(0, 0, 0, .55);
  }
}
```

Переопределяются **только переменные**. Ни одно правило ниже не дублируется,
поэтому тёмная тема не может «отстать» от светлой при добавлении новых стилей.

Переключателя нет — берётся системная настройка. Одной кнопкой меньше, и
поведение совпадает с ожиданиями пользователя.

`color-scheme: light dark` в `:root` говорит браузеру, что страница умеет обе
темы, — тогда и стандартные элементы (галочки, выпадающие списки, полосы
прокрутки) рисуются в тон.

В тёмной теме `--accent` светлее, чем в светлой: синий `#4d6bfe` на тёмном фоне
читается плохо, поэтому текст и линии берут `#6f9bff`, а на залитой им кнопке
текст тёмный (`--accent-fg`). Главная кнопка остаётся фирменно-синей с белым
текстом — для неё отдельная пара `--primary`/`--primary-fg`.

Заметьте, что смысловые цвета в тёмной теме тоже сдвинуты: `--event` из
светло-голубого становится тёмно-синим. Сохраняется не сам цвет, а роль:
события синеватые, элементы зеленоватые, в обеих темах.

## Оформление в духе DeepSeek

Общий вид повторяет приёмы чата DeepSeek:

- **поверхности:** рабочая область и шапка белые (`--panel`), палитра,
  инспектор и боковая колонка марковского окна — чуть голубоватые (`--side`);
  холст — белый с точечной сеткой (`--dot`);
- **акцент** — синий `#4d6bfe`; им же написано «CRA» в шапке;
- **светлые тона** — небесно-голубые (`--accent-soft` `#dbeafe`, `--event`,
  `--bar`), подложки и чипы — нейтрально-серые: светлые оттенки самого
  индигового акцента выглядят лавандовыми, почти розовыми;
- **«пилюли»:** вкладки «Схема»/«JSON», кнопка «Рассчитать», «свернуть»,
  чипы элементов в таблицах скруглены полностью (`border-radius: 999px`);
  активная вкладка залита мягким акцентом (`--accent-soft`) с текстом
  `--accent-ink` — как переключатели режимов у DeepSeek;
- **тихие кнопки:** кнопки палитры — строки списка без рамки, подсвечиваются
  при наведении (`--hover`), как беседы в боковой панели;
- **выделение** синее (`--sel`), как выбранная беседа; тёплых тонов —
  оранжевого, розового, коричневого — нет: предупреждения синие со знаком
  ⚠, ошибки и состояние отказа марковского узла — красная линия без
  заливки;
- **поля ввода** скруглены на `--radius`, при фокусе — акцентная рамка и мягкое
  кольцо (`box-shadow` цвета `--accent-soft`);
- **окна** — `--radius-lg`, тень `--shadow` вместо жёсткой рамки, фон под окном
  чуть размыт (`backdrop-filter`).

Наведение на кнопку задано одним правилом:

```css
button:hover:not(:disabled) { background-color: var(--hover); }
```

Его специфичность — `(0,2,1)`, выше, чем у `.tab.active` `(0,2,0)`, поэтому
активная вкладка записана как `.tabs .tab.active`: иначе при наведении она
теряла бы заливку. Правило для любого нового выбранного состояния кнопки
должно быть не слабее.

## Цветовое кодирование схемы

```css
.node.event .body            { fill: var(--event); stroke: var(--event-br); }
.node.gate .body,
.node.sfc .body              { fill: var(--gate);  stroke: var(--gate-br); }
.node.top .body              { stroke-width: 3; }
.node.selected .body         { stroke: var(--sel); stroke-width: 3; }
```

Три независимых визуальных признака:

| Признак | Как показан |
|---|---|
| роль (событие / элемент) | цвет заливки |
| вершина | толстая рамка |
| выделение | синяя рамка |

Они не конфликтуют: выделенная вершина-событие остаётся голубой, с толстой
синей рамкой. Все три факта читаются одновременно.

## Виды дуг СФЦ

```css
.edge          { stroke: var(--edge); stroke-width: 2; marker-end: url(#arrow); }
.edge.inverse  { stroke-dasharray: 5 3; }
.edge.conj     { stroke: var(--gate-br); }
.edge-label.conj { fill: var(--gate-br); }
.edge-label.disj { fill: var(--accent); }
```

Каноническая СФЦ различает дуги по двум независимым признакам, и каждый получил
свой визуальный канал:

- **вид** (конъюнктивная / дизъюнктивная) — цвет линии;
- **выход** (прямой / инверсный) — сплошная или пунктирная.

Плюс текстовая метка `&` / `≥1` и `¬`, которую рисует `app.js`. Дублирование
намеренное: цветовое кодирование бесполезно при чёрно-белой печати и для людей
с нарушением цветовосприятия, а пунктир и подпись работают всегда.

## Зона попадания по дуге

```css
.edge-hit { stroke: transparent; stroke-width: 12; fill: none; cursor: pointer; }
```

Прозрачная линия толщиной 12 пикселей под каждой видимой связью. Именно она
принимает клики — в двухпиксельную линию попасть мышью практически невозможно.
Приём разобран в [web-app-js.md](web-app-js.md).

## Курсоры

```css
.node rect, .node .body { cursor: grab; }
.node.dragging rect     { cursor: grabbing; }
.port                   { cursor: crosshair; }
.port:hover             { fill: var(--accent); }
```

Курсор сообщает, что произойдёт, ещё до нажатия: «ладонь» — можно тащить,
«перекрестие» — начнётся связь. Подсветка порта при наведении подтверждает, что
цель захвачена, — важно, потому что порт маленький (радиус 6 пикселей).

## Текст в SVG

```css
.node text { font: 12px var(--font); fill: var(--text);
             pointer-events: none; user-select: none; }
```

Две последние строки существенны для поведения:

- `pointer-events: none` — подпись не перехватывает мышь, поэтому клик по тексту
  считается кликом по узлу;
- `user-select: none` — при перетаскивании не выделяется текст (иначе схема
  покрывалась бы синими прямоугольниками выделения).

Шрифт `--font` — Inter, если он установлен в системе, иначе системный шрифт
платформы (`Segoe UI`, `system-ui`, Roboto, Noto Sans). Ничего не загружается
из сети, что обязательно для работы в закрытом контуре.

## Раскладка

```css
html, body { height: 100%; margin: 0; }
.tabview { display: none; flex: 1 1 auto; min-height: 0; }
.tabview.active { display: flex; }
.canvas-wrap { flex: 1 1 auto; min-width: 0; position: relative; }
```

Flexbox на всю высоту окна: палитра и инспектор фиксированной ширины, холст
занимает остальное.

`min-height: 0` и `min-width: 0` — обязательная поправка для flex: по умолчанию
элемент не сжимается меньше своего содержимого, из-за чего холст выталкивал бы
раскладку за пределы экрана. Без этих двух строк появлялись бы полосы прокрутки
у всей страницы.

## Моноширинный шрифт для чисел

```css
.node .sub { font-size: 10px; fill: var(--muted); font-family: var(--mono); }
```

Параметры распределений (`λ=1e-4`, `q=0.01`) выводятся моноширинным шрифтом.
Цифры при этом одинаковой ширины, и значения у соседних узлов зрительно
выравниваются — сравнивать порядки величин заметно проще.
