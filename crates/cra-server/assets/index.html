Управление

ЛКМ по холсту — снять выделение. Тянуть узел — переместить. Тянуть от нижнего порта (○) к другому узлу — вход. Клик по стрелке — выбрать дугу (в СФЦ: тип И/ИЛИ и прямой/инверсный выход задаются в инспекторе). Del — удалить.

Выберите узел, чтобы задать параметры.
