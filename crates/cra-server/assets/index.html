Управление

ЛКМ по холсту — снять выделение. Тянуть узел — переместить. Ctrl+клик по узлу — добавить к выделению или убрать, Ctrl+A — выделить все; выделенные узлы тащатся вместе. Тянуть от нижнего порта (○) к другому узлу — вход. В СФЦ новая дуга получает тип из «Новая дуга» (клавиши 1–4); Shift+клик по дуге — присвоить ей этот тип. Клик по стрелке — выбрать дугу и поправить её в инспекторе. Del — удалить выделенное, Esc — снять выделение. Ctrl+Z — отменить правку, Ctrl+Y — повторить.

Выберите узел, чтобы задать параметры.
